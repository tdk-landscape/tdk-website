Quick Start

From zero to a running local stack in {{ site.data.tdk.quickstart_time }}.

Prerequisites

  • Docker installed
  • Tilt installed
  • Node.js {{ site.data.tdk.prereq_node }} (for frontend tooling)

Installation

Install the latest public binary directly from the TDK CLI release channel. The installer detects Linux, macOS, Intel, and Arm automatically.

One-line install

terminal
curl -fsSL https://tdk-landscape.github.io/install.sh | sh

Manual download

Download a binary from the public release repo if you prefer to install it yourself.

terminal
curl -fsSL -o tdk https://github.com/tdk-landscape/tdk-cli-releases/releases/latest/download/tdk-linux-amd64
chmod +x tdk
sudo mv tdk /usr/local/bin/tdk

GitHub Releases

Binaries ship with each release from tdk-landscape/tdk-cli-releases. The CLI source can stay private while these release assets stay public.

Docker Compose

Use Docker Compose if you want to try TDK without installing the binary on your host.

terminal
git clone https://github.com/tdk-landscape/tdk-docker-compose-example.git
cd tdk-docker-compose-example
docker compose run --rm tdk tdk --version
docker compose run --rm tdk tdk project --yes

Verify installation

terminal
tdk --version
# tdk-cli v1.0.0

Create your first service

1 — Create a new project

terminal
mkdir my-service
cd my-service
tdk project --yes

2 — Create a backend resource

terminal
tdk resource api --type backend --stack pre-alpha --path services/pre-alpha/api

3 — Add a dependency

TDK/Tilt reads boot order from internalDependencies. This example makes api depend on database.

terminal
tdk resource database --type backend --stack pre-alpha --path services/pre-alpha/database
services/pre-alpha/api/service.json
{
  "name": "api",
  "type": "backend",
  "stack": "pre-alpha",
  "port": 4000,
  "internalDependencies": ["database"]
}

4 — Inspect service.json

service.json
{
  "name": "api",
  "type": "backend",
  "stack": "pre-alpha",
  "port": 4000,
  "internalDependencies": ["database"]
}

5 — Validate configs

terminal
tdk project --check

This validates .tdk/project.json and the generated files in .tdk/.tdk-out/.

6 — Run the stack

terminal
tdk up pre-alpha

Success

Your service is now running locally. Visit http://localhost:3000 — and every new teammate who clones the repo gets the same result in minutes, not weeks.
