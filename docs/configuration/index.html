Configuration

The service.json file is the single source of truth for each service. Here is the complete schema.

service.json schema

service.json — annotated
{
  "appName": "my-service",           // Required: unique name
  "appType": "backend",             // Required: backend | frontend | library | sdk | worker | migrator
  "port": 3000,                     // Required: service port
  "stack": "api",                   // Optional: stack grouping
  "featuresEnabled": [                      // Optional: features to enable
    "typescript",
    "vite",
    "bun"
  ],
  "replicas": 1,                    // Optional: number of replicas
  "backendName": "api-backend",     // Optional: backend for frontend
  "basePath": "/api",               // Optional: URL base path
  "dependsOn": [         // Optional: other services
    "database",
    "cache"
  ],
  "envVars": {                      // Optional: environment variables
    "NODE_ENV": "development",
    "API_URL": "http://localhost:3001"
  }
}

Required fields

appName

The unique identifier for your service. Lowercase with hyphens.

service.json
"appName": "order-service"

appType

The type of service. Determines which generators run.

    {% for t in site.data.tdk.app_types %}
  • {{ t.name }} — {{ t.desc }}
    • {% endfor %}

port

The port your service listens on.

service.json
"port": 3000

Optional fields

features

List of features to enable. Triggers corresponding generators.

    {% for f in site.data.tdk.manifest_features %}
  • {{ f.name }} — {{ f.desc }}
    • {% endfor %}

stack

Groups related services for selective startup and Tilt orchestration.

service.json
"stack": "order-management"

dependsOn

Other services this service depends on. TDK resolves boot order automatically.

service.json
"dependsOn": ["database", "redis", "auth-service"]

package.json scripts

Each service also needs a package.json next to its service.json, with npm scripts required by appType. See package.json Scripts for the full list and how tdk doctor checks it.
